# Face Recognition

The Face Recognition Project is a person identification process which can be used in real time project such as Smart Attendance System, CCTV Surveillance, etc to recognize the face of a person. This project is based on the algorithm called Haarcascade frontalface which recognizes the face of a person by a particular pattern of number sequences for each part of the face. This project consists of two parts: Face Dataset Creation (Part 1) and Face Recognition (Part 2).

Part 1 - Face Dataset Creation: 
In this phase the data containing the faces of persons along with their names. Importing the required libraries like cv2 (Computer Vision) and os. Using the os library we check that the directory we are creating with the person's name and images is already exists in our dataset. If the directory exists we replace it otherwise we create a new directory with the name of the person. Using haarcascade frontalface algorithm the face of the person is captured through a web camera or the camera that is connected and creates the dataset of the person with these images. The dataset is consists of 30 images of each person in the gray scale type which is converted using cv2 library. After capturing each image of each person it resizes the image to the size of width 120 and height 110 and saves the image with its count as .jpg format. And then after capturing 30 images of a person the access to camera will be released. To collect the dataset for another person run the code again.

Part 2 - Face Recognition:
In this phase the person is get recognized by their name. If the person is unknown then it will show Unknown Person and save the image of the person as unknown as .jpg format. The libraries required for this project are cv2, numpy and os. Haarcascade frontalface algorithm is used to find the patterns in the face of a person and then we checks these patterns with our dataset. Our model is trained with the dataset that is collected in the Face Dataset Creation phase. Our model uses the cv2.LBPHFaceRecognizer_create() method to recognize the faces of the persons from the training phase with the dataset. And then in testing phase we test the model by providing the face of a person, while predicting the name of the person the image is converted into gray scale type and matches the patterns with the dataset. If the pattern matches any of the person's data then it will show the name of that person. If none of our dataset is matched then the person is said to be unknown. And finally after recognition of the person until the program is terminated the access to camera is been released.
